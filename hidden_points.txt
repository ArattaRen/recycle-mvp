# Recycle Radar — скрытые точки (не попадают на карту).
# Формат: по одному идентификатору OSM в строке: node/<id> или way/<id>.
# Строки, начинающиеся с #, игнорируются.
#
# Процедура скрытия по обращению владельца точки:
# 1. Добавить строку с идентификатором (например: node/1234567890).
# 2. Залить этот файл на GitHub (Commit changes).
# 3. Нажать «Run workflow» в Actions (или ждать планового прогона) —
#    точка исчезнет при следующей пересборке данных.
